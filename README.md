# JevArchive

RisuAI 장기기억 플러그인. 대화를 **원문 그대로** 간직하고, 답장마다 지금 필요한 장면만 꺼내 넣어요.
인물 · 관계 · 약속 · 사건도 알아서 정리해서 화면으로 보여 줘요. 글 쓰는 모델 없이 **Jev(고르기만 하는 판단 모델) + 임베딩**만 써요.

## 화면

다크 모드 전용. 폰은 아래 탭 + 아래에서 올라오는 시트, PC는 왼쪽 메뉴 + 오른쪽 서랍.

- **지금** — 이야기 시간(상태창에서 읽음) · 지금 나온 인물 · *이번 답장에 넣은 기억* 카드 · 진행 중인 약속 · 감독 힌트 · 최근 일어난 일
- **인물** — 관계도(끌어서 이동, 두 손가락/휠로 확대). 선 색은 가까움(분홍) / 멀어짐(파랑), 굵기는 함께 나온 횟수. 인물을 누르면 관계 · 약속 · 한 일
- **약속** — 진행 중 / 끝남. 지켜짐 · 취소 · 다시 열기
- **기억** — 옛날 대화 찾기, 📌 고정(매번 넣기)
- **설정** — 연결, 기억 넣기(가볍게 · 균형 · 꼼꼼하게), 이야기 기능, 도구, 진단

처음 열면 시작 안내가 나와요. 키 하나 넣고 다음, 다음, 완료.

## 어떻게 동작하나

**보낼 때 (기억)**

1. Risu가 안 보낸 이전 메시지만 문장 2~4개 조각으로 자르고 임베딩해요. 버리는 문장이 없어요.
2. 임베딩 + 글자(이름 · 숫자) + 사건 카드로 후보를 찾아요.
3. Jev가 조각마다 "지금 필요한가" 0~3점. 빠진 근거가 있으면 한 번 더 찾아요.
4. 고정한 기억 → 방금 흐름 → Jev가 고른 조각(+앞뒤)을 원래 순서대로 최신 입력 앞에 넣어요.
5. 맨 위에 짧게: 지금 시간 · 지금 나온 인물끼리의 관계 · 열린 약속. 예산의 30%를 넘지 않아요.

**답장 뒤 (이야기, 뒤에서)**

- 메시지 몇 개씩 Jev 1~2번: 새 인물인지, 둘이 가까워졌는지 / 멀어졌는지, 약속이 생겼는지 / 지켜졌는지, 사건 카드("누가 → 누구에게: 무엇을").
- 보내기를 기다리게 하지 않아요.

**감독 힌트 (선택, 기본 꺼짐)**

- 회상과 *같은* Jev 호출에 질문 몇 개를 더 얹어서 템포 · 꺼낼 약속 · 먼저 움직일 인물 · 분위기를 골라요. 호출이 늘지 않아요.
- 메인 모델에게는 "참고용, 사용자 지시가 먼저"라고 붙여서 넣어요.

### 왜 이렇게 만들었나

- **요약 대신 원문.** 요약은 한 번 틀리면 계속 틀려요. 원문은 다시 읽으면 돼요.
- **카드는 넣는 게 아니라 찾는 열쇠.** 카드 문장이 맞으면 그 카드가 나온 *원문*을 꺼내요. 카드만 넣으면 디테일이 빠져서 기억력이 떨어져요.
- **이야기 정리는 답장 뒤에.** 보낼 때 느려지지 않게.

### 기억력 확인

V7 장기기억 시나리오(80턴, 정답 55개, Risu 채팅 범위 2개), 실제 Jev + Voyage 임베딩:

| | 맞힌 수 | 넣은 기억 (평균) |
|---|---|---|
| HypaJev | 51/55 | 386토큰 |
| **JevArchive** (이야기 · 카드 · 감독 힌트 켬) | **52/55** | 429토큰 |

이야기 기능을 켜도 기억력은 떨어지지 않았어요. 대신 Jev 질문이 늘어요(답장 뒤 정리, 대부분 사건 카드). 아끼려면 설정에서 사건 카드를 끄세요.

## 저장

- **원문:** Risu 채팅 그대로. 따로 저장하지 않아요.
- **이 기기:** 조각 벡터(조각마다 32바이트)와 사건 카드. 다른 기기에서는 다시 만들어요.
- **세이브 파일:** 설정 + 채팅마다 이야기 장부(인물 · 관계 · 약속 · 고정, 보통 몇 KB).

## 설치

1. [`jevarchive.js`](https://raw.githubusercontent.com/happydesk213124/JevArchive/main/jevarchive.js)를 받습니다.
2. RisuAI → 설정 → 플러그인 → 플러그인 추가에서 파일을 고릅니다.
3. 플러그인 설정의 **JevArchive**(또는 채팅 화면의 🗂️ 버튼)를 열면 시작 안내가 나와요.
4. Risu 채팅 범위(최대 컨텍스트)를 줄이면 토큰이 줄어요. Risu 자체 메모리(하이파 · 수파)는 꺼 두세요.
5. 이미 긴 채팅이면 **지금** 화면의 "지금 색인", 그다음 "지금 정리"를 한 번씩 누르세요.

다른 장기기억 플러그인(HypaJev, JevHypa 등)과 같이 켜면 기억이 두 번 들어가요. 하나만 켜 두세요.

## 설정

| 설정 | 기본 | 뜻 |
|---|---|---|
| 기억 넣기 | 균형 (600토큰 · 후보 16) | 가볍게 400 · 12 / 꼼꼼하게 1200 · 24 |
| 인물 · 관계 · 약속 기록 | 켬 | 답장 뒤 뒤에서 정리 |
| 사건 카드 | 켬 | 인물 페이지 + 찾기 열쇠. Jev 질문이 꽤 늘어요 |
| 감독 힌트 | 끔 | 템포 · 약속 · 인물 · 분위기 귀띔 |
| 넣는 위치 | 최신 입력 앞 | 프롬프트에 `[jevarchive]`를 써 두면 그 자리 |

## 자동 업데이트

파일 머리의 `//@update-url`로 RisuAI가 이 저장소 `main`의 새 `//@version`을 감지해요.
