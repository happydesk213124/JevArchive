# JevArchive

RisuAI 장기기억 플러그인. 대화를 **문장 하나하나**로 정리해 두고, 답장마다 지금 필요한 문장만 **원래 문장 그대로** 꺼내 넣어요.
인물 · 관계 · 약속 · 비밀 · 사건도 알아서 정리해서 화면으로 보여 줘요. 글 쓰는 모델 없이 **Jev(고르기만 하는 판단 모델) + 임베딩**만 써요.

## 화면

다크 모드 전용. 폰은 아래 탭 + 아래에서 올라오는 시트, PC는 왼쪽 메뉴 + 오른쪽 서랍.

- **지금** — 이야기 시간(상태창에서 읽음) · 지금 나온 인물 · *이번 답장에 넣은 기억* 카드 · 진행 중인 약속 · 감독 힌트 · 최근 일어난 일
- **인물** — 관계도(끌어서 이동, 두 손가락/휠로 확대). 선 색은 가까움(분홍) / 멀어짐(파랑), 굵기는 함께 나온 횟수. 인물을 누르면 관계 · 약속 · 한 일
- **약속 · 비밀** — 약속은 진행 중 / 끝남. 비밀은 "누가 · 누구 모르게"로 모으고 내용은 스포일러로 가려요(눌러서 보기). 상대가 알게 되면 "드러남"으로 닫혀요
- **기억** — 정리된 기억(종류 · 칸) 찾기, 원문 보기, 📌 고정(매번 넣기)
- **설정** — 연결, 기억 넣기(가볍게 · 균형 · 꼼꼼하게), 이야기 기능, 도구, 진단

처음 열면 시작 안내가 나와요. 키 하나 넣고 다음, 다음, 완료.

## 어떻게 동작하나

**도서관처럼 생각하면 쉬워요**

- 대화 하나 = 책 한 권, 문장 하나 = 한 줄.
- **정리 (보낸 뒤 뒤에서):** 책을 한 줄씩 자르고, "응." · 질문 같은 쓸데없는 줄은 버려요. Jev가 줄마다 스티커(사건 · 행동 · 사실 · 약속 · 비밀)를 붙여요. 누가 · 누구랑 · 누구에게 · 언제 · 어디서 · 무엇을 · 어떻게 · 왜 칸은 그 줄이 실제로 쓰일 때(답장에 들어갔거나 최근 사건일 때)만 나눠서 비용을 아껴요. 언제 · 어디서가 비면 상태창 값으로 채워요. "바뀌었다 · 현재 · 정정" 같은 줄엔 *바뀜 표시*. 줄마다 찾기용 지문(임베딩)을 붙여요.
- **꺼내기 (보낼 때):** 지문으로 비슷한 **책** 몇 권을 꺼내고(질문이 "지금 · 현재 · 아직"이면 바뀜 표시가 있는 책 먼저), Jev가 그 책들의 줄을 번호 목록으로 한꺼번에 읽고 "지금 필요해?" 0~3점 (설명은 한 번만, 질문은 번호만이라 요청이 작아요). 높은 줄과 바로 옆 줄을 원래 문장 그대로, 시간 순서대로 넣어요.
- 맨 위에 짧게: 지금 시간 · 지금 나온 인물끼리의 관계 · 열린 약속 · 숨기는 비밀("B는 아직 모름"). 예산의 30%를 넘지 않아요.
- 막 밀려난 메시지는 아직 정리 전이라, 그 끝부분(방금 흐름)만 원문으로 이어 줘요.

**보낸 뒤 (이야기, 뒤에서)**

- 메시지 몇 개씩 Jev 1~2번: 새 인물인지, 둘이 가까워졌는지 / 멀어졌는지, 약속이 생겼는지 / 지켜졌는지, 비밀이 생겼는지 / 드러났는지.
- 보내기를 기다리게 하지 않아요. 메인 모델이 답을 쓰는 동안 같이 돌아요. 답장이 온 뒤에는 아무것도 안 해요.

**감독 힌트 (선택, 기본 꺼짐)**

- 회상과 *같은* Jev 호출에 질문 몇 개를 더 얹어서 템포 · 꺼낼 약속 · 먼저 움직일 인물 · 분위기를 골라요. 호출이 늘지 않아요.
- 메인 모델에게는 "참고용, 사용자 지시가 먼저"라고 붙여서 넣어요.

**연출 카드 (감독 힌트 안에서)**

- 사람이 미리 써 둔 짧은 연출(예: "침묵의 무게", "알리바이의 구멍", "모닥불")을 Jev가 지금 장면에 맞게 *고르기만* 해요. 글은 모델이 만들지 않아요.
- 기본 134장: 기본 30 · 로맨스 24 · 일상 20 · 미스터리 20 · 판타지 20 · 공포 20. 내 카드도 만들고, JSON으로 나눌 수 있어요.
- 고르는 순서: 조건(다른 인물이 있나 · 관계 온도 · 열린 약속 · 최근에 쓴 카드는 쉼) → **장르 자동 맞춤**(Jev가 이 채팅의 장르를 판단) → 임베딩으로 12장 → Jev가 하나 또는 "없음".
- 카드 속 `{char}` `{user}` `{other}`는 이름으로, 조사도 이름에 맞게 바뀌어요(하윤이 / 지호가).
- 빈도: 가끔 / 보통 / 자주. "맞는 게 없다"는 확률이 낮을 때만 넣어요.
- 실제 Jev로 장르가 다른 장면 6개 × 3번: 18번 중 17번 장면에 맞는 카드를 골랐어요(나머지 1번은 "없음").

### 왜 이렇게 만들었나

- **요약 대신 원문.** 요약은 한 번 틀리면 계속 틀려요. 원문은 다시 읽으면 돼요.
- **카드는 넣는 게 아니라 찾는 열쇠.** 카드 문장이 맞으면 그 카드가 나온 *원문*을 꺼내요. 카드만 넣으면 디테일이 빠져서 기억력이 떨어져요.
- **이야기 정리는 뒤에서.** 보낸 직후 시작하지만 기다리지 않아서 보내기가 느려지지 않아요.

### 기억력 확인

V7 장기기억 시나리오(80턴, 정답 55개, Risu 채팅 범위 2개), 실제 Jev + Voyage 임베딩:

|---|---|---|
| HypaJev | 51/55 | 386토큰 |
| **JevArchive 0.0.9** (원문 조각) | 52/55 | 445토큰 |
| JevArchive 0.1.0 (문장 · 책 단위로 꺼내기) | 52/55 | 407토큰 |

이야기 기능과 연출 카드를 켜도 기억력은 떨어지지 않았어요. 대신 Jev 질문이 늘어요(뒤에서 하는 이야기 정리, 대부분 사건 카드). 아끼려면 설정에서 사건 카드를 끄세요.

## 저장

- **원문:** Risu 채팅 그대로. 따로 저장하지 않아요.
- **이 기기:** 조각 벡터(조각마다 32바이트)와 사건 카드. 다른 기기에서는 다시 만들어요.
- **세이브 파일:** 설정 + 채팅마다 이야기 장부(인물 · 관계 · 약속 · 고정, 보통 몇 KB).

## 설치

1. [`jevarchive.js`](https://raw.githubusercontent.com/happydesk213124/JevArchive/main/jevarchive.js)를 받습니다.
2. RisuAI → 설정 → 플러그인 → 플러그인 추가에서 파일을 고릅니다.
3. 플러그인 설정의 **JevArchive**(또는 채팅 화면의 🗂️ 버튼)를 열면 시작 안내가 나와요.
4. Risu 채팅 범위(최대 컨텍스트)를 줄이면 토큰이 줄어요. Risu 자체 메모리(하이파 · 수파)는 꺼 두세요.
5. 이미 긴 채팅이면 **지금** 화면의 "지금 색인", 그다음 "지금 정리"를 한 번씩 누르세요.

다른 장기기억 플러그인(HypaJev, JevHypa 등)과 같이 켜면 기억이 두 번 들어가요. 하나만 켜 두세요.

## 설정

| 설정 | 기본 | 뜻 |
|---|---|---|
| 기억 넣기 | 균형 (600토큰 · 후보 16) | 가볍게 400 · 12 / 꼼꼼하게 1200 · 24 |
| 인물 · 관계 · 약속 기록 | 켬 | 보낸 뒤 뒤에서 정리 |
| 사건 카드 | 켬 | 인물 페이지 + 찾기 열쇠. Jev 질문이 꽤 늘어요 |
| 관계 횟수 (성인) | 끔 | 두 사람이 실제로 관계를 가진 횟수. 같은 장면은 한 번, 인물 페이지에서 고치기 |
| 감독 힌트 | 끔 | 템포 · 약속 · 인물 · 분위기 귀띔 |
| 연출 카드 | 켬 (감독 힌트를 켰을 때) | 장면에 맞는 연출 한 줄. 장르 자동 맞춤 · 빈도 · 묶음 · 내 카드 |
| 넣는 위치 | 최신 입력 앞 | 프롬프트에 `[jevarchive]`를 써 두면 그 자리 |

## 자동 업데이트

파일 머리의 `//@update-url`로 RisuAI가 이 저장소 `main`의 새 `//@version`을 감지해요.
